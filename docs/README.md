# Tài liệu

| File / thư mục | Nội dung |
|---|---|
| `ARCHITECTURE.md` | Chi tiết kỹ thuật 4 giai đoạn, tham số, các bẫy |
| `DATA_CONTRACTS.md` | Hợp đồng giao tiếp dữ liệu (I/O, schemas, mock test data) |
| `TEAM.md` | Phân công 4 người, ranh giới trách nhiệm |
| `ROADMAP.md` | Task theo tuần, cổng kiểm soát, rủi ro |
| `adr/` | Architecture Decision Records |
| `report/` | Đề cương, báo cáo cuối kỳ |
| `slides/` | Slide thuyết trình |
| `diagrams/` | Sơ đồ nguồn (drawio, plantuml) |

## Nguyên tắc

- Quyết định gì ảnh hưởng người khác -> ghi vào `adr/`, không chỉ nói miệng.
- Tài liệu đi kèm code trong cùng PR, không để "làm xong rồi viết sau".
